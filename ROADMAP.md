# Aura Roadmap

This roadmap represents the long-term direction of Aura.

Dates are intentionally omitted.

Development is milestone-driven rather than deadline-driven.

---

# Current Status

**Phase 0 — Research & Specification** ✅

Completed

- Product research
- Product specification
- UX specification
- System architecture
- Design system
- Engineering principles
- Repository foundation

---

# Phase 1 — Foundation

Establish the engineering foundation of Aura.

Goals:

- Repository bootstrap
- Runtime initialization
- Configuration system
- Logging
- Diagnostics
- Event bus
- Build system
- Testing infrastructure
- CI/CD

Deliverable:

A stable runtime capable of starting, shutting down, and processing events.

---

# Phase 2 — Core Runtime

Build Aura's core intelligence.

Goals:

- Event normalization
- Context engine
- Priority engine
- State machine
- Persistence
- Recovery
- Scheduling

Deliverable:

A deterministic runtime capable of understanding and managing desktop activity.

---

# Phase 3 — Surface Layer

Build Aura's interaction surfaces.

Goals:

- Surface manager
- Compact surface
- Expanded surface
- Placement engine
- Window management
- Interaction framework
- Animation integration

Deliverable:

A responsive Windows-native interface driven entirely by runtime state.

---

# Phase 4 — Core Features

Implement the first user-facing capabilities.

Initial features include:

- Clipboard history
- Screenshot management
- Downloads
- Media controls
- Notifications
- Search
- History
- Quick actions

Deliverable:

The first usable version of Aura.

---

# Phase 5 — Ecosystem

Expand Aura beyond the MVP.

Goals:

- Plugin runtime
- Plugin SDK
- Developer documentation
- Extensibility
- Custom integrations

Deliverable:

Aura becomes an extensible productivity platform.

---

# Phase 6 — Polish

Prepare Aura for long-term public use.

Goals:

- Accessibility
- Performance optimization
- Memory optimization
- Power efficiency
- Localization
- Installer
- Packaging
- Documentation
- Testing

Deliverable:

Production-ready release candidate.

---

# Future Vision

Potential future areas include:

- AI-assisted workflows
- Cross-device continuity
- Cloud synchronization
- Enterprise capabilities
- Advanced automation
- Additional productivity integrations

These ideas are exploratory and not part of the current MVP.

---

# Guiding Principles

Every milestone should:

- Reduce context switching.
- Preserve user attention.
- Respect the existing architecture.
- Follow the Engineering Principles.
- Maintain a Windows-native experience.
- Prioritize quality over speed.

Aura will grow deliberately.

Features are added only when they strengthen the product rather than increase complexity.
